# Aradhi Tower - Premium Real Estate by CPH Ltd. Bangladesh

"Your dream is our deposit."

A professional, high-performance real estate developer website for **Aradhi Tower**, a flagship project of **CPH Ltd. Bangladesh**. Built with a sophisticated beige and gold aesthetic, this platform represents the pinnacle of luxury urban living.

## 🚀 Key Features

- **Professional Aesthetic**: A premium beige, gold, and charcoal palette designed for a luxury feel.
- **Next.js 15+ App Router**: High-performance architecture with TypeScript for robust development.
- **PWA Capabilities**: Fully installable as a mobile app with offline support and fast loading.
- **Architectural Branding**: Custom-generated professional logo based on architectural principles.
- **Responsive Layout**: Stunning asymmetric design that adapts perfectly to desktop and mobile devices.
- **SEO Optimized**: Complete with metadata, manifest, and semantic HTML for superior search visibility.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/)
- **Branding**: Aradhi Tower (by CPH Ltd. Bangladesh)
- **Styling**: CSS Modules with Vanilla CSS Design Tokens
- **Typography**: Outfit (Headings) & Inter (Body)
- **Deployment**: PWA Ready with `@ducanh2912/next-pwa`

## 📂 Project Structure

```text
src/
├── app/              # App Router pages (Home, About, Projects, Contact)
├── components/       # Scoped layout and UI components
├── styles/           # Centralized design tokens (vars.css)
└── public/           # Performance-optimized assets and PWA manifest
```

## 🏁 Getting Started

1. **Setup**:
   ```bash
   npm install
   ```

2. **Development**:
   ```bash
   npm run dev
   ```

3. **Production Build**:
   ```bash
   npm run build
   ```
