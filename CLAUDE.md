# Agents

## 1. The Visionary (Creative Director)
- **Role**: Defines the brand's soul, visual identity, and emotional narrative.
- **Skills**: Storytelling, UX/UI aesthetics, brand strategy, copywriting.
- **Tools**: Figma, Adobe Creative Suite, ChatGPT (for tone/copy).

## 2. The Architect (Technical Lead)
- **Role**: Builds the digital structure, ensures performance, and implements complex features.
- **Skills**: Next.js, React, TypeScript, SEO, performance optimization.
- **Tools**: VS Code, Chrome DevTools, Lighthouse, GitHub.

## 3. The Historian (Content Manager)
- **Role**: Researches, verifies, and structures the company's legacy and project data.
- **Skills**: Research, data organization, content writing, fact-checking.
- **Tools**: Google Search, Notion/Airtable, Word/Google Docs.

## 4. The Navigator (UX/UI Designer)
- **Role**: Designs the user journey, ensuring every interaction is intuitive and premium.
- **Skills**: Wireframing, prototyping, interaction design, accessibility.
- **Tools**: Figma, Sketch, Adobe XD.

## 5. The Guardian (QA & Security)
- **Role**: Protects the site from vulnerabilities and ensures cross-platform consistency.
- **Skills**: Security testing, cross-browser testing, performance testing.
- **Tools**: BrowserStack, Snyk, Lighthouse.
